About This Project

Login Time-Based Detection of Suspicious Logins

This project is a Machine Learning based cyber security system developed to identify suspicious login attempts by analysing user login behaviour.


Objectives

  • Detect suspicious login attempts.
  • Improve account security.
  • Reduce unauthorized access.
  • Support security monitoring.

Technologies Used

  • Python
  • Flask
  • Pandas
  • Scikit-learn
  • Random Forest
  • HTML
  • CSS

Dataset

Simulated login dataset containing 2000 user login records with normal and suspicious login behaviour.


Machine Learning Model

Random Forest Classifier trained using behavioural login features such as login hour, failed attempts, login frequency, device, browser and weekday.
