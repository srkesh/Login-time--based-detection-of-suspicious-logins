# Login-time--based-detection-of-suspicious-logins
Login Time-Based Detection of Suspicious Logins is a Flask-based web application that analyzes user login behavior to detect suspicious login attempts using a Random Forest model. It provides real-time predictions, an interactive dashboard, and visual insights to enhance login security through behavioral analysis.


Login Time-Based Detection of Suspicious Logins

This project is a web-based application developed to analyze user login behavior and identify suspicious login attempts using machine learning techniques. The system examines login-related attributes such as login hour, day of the week, login status, failed attempts, login frequency, browser type, device type, month, day, and weekend information to determine whether a login attempt is normal or suspicious.

The application is built using Python, Flask, and Scikit-learn, with the Random Forest algorithm serving as the prediction model. Users can enter login details through an intuitive web interface and receive instant prediction results. The system also includes a dashboard that displays data visualizations, model performance metrics, and exploratory data analysis charts to provide better insight into login behavior.

Features:

Login behavior analysis
Suspicious login detection
Random Forest classification model
Flask-based web application
Interactive prediction form
Dashboard with charts and analytics
Feature importance visualization
Confusion matrix and model performance metrics
Responsive and user-friendly interface
